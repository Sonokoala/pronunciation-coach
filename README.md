# Pronunciation Coach（英語発音の採点アプリ）

英語のプレゼン原稿を読み上げると、Microsoft Azure の **Pronunciation Assessment** が音素（1つ1つの音）単位で採点する、ブラウザで使うアプリです。
英語の内容は理解できても、口に出して伝えるのが苦手な日本語話者のために作りました。

[Study Notes JP](https://github.com/Sonokoala/study-notes-app-jp) が授業の録画から作る英語のプレゼン（`プレゼン_EN.pptx`）をそのまま読み込めます。
原稿の太字は「強く読む語」として赤で表示されるので、授業で学んだ内容を、アクセントを直しながら英語で発表する練習までつなげられます。

- **総合点**と4つの指標：正確さ / 流暢さ / 完全性 / 抑揚・リズム（抑揚は en-US のみ）
- **単語ごとの色分け**（緑・黄・赤）、読み飛ばし・余分な単語の検出
- 単語をクリックすると**音素ごとの点数**と「/ɹ/ が /l/ に聞こえた」などの指摘、日本語の発音のコツ
- **今回のポイント**：その録音で一番弱かった音 TOP3 とコツ
- **苦手な音 TOP10**：これまでの全録音から自動で集計（ブラウザに保存）
- お手本の読み上げ（アメリカ・オーストラリア・イギリス英語、ゆっくり再生あり）、自分の録音の再生
- 読み込めるもの：PowerPoint（スライドの文、またはノート欄の原稿）、テキストの原稿や文字起こし（.txt）、それらが入ったフォルダ
- 練習の記録は `notes\練習ログ.csv` に残ります

## 1. 準備（初回だけ・約10分）

Python 3.11 以降が必要です（https://www.python.org/downloads/ 。インストール画面で **Add python.exe to PATH** にチェック）。追加のライブラリはいりません。

Azure の **無料枠（F0）** で使えます。音声認識は毎月5時間まで無料です。

1. <https://azure.microsoft.com/free> で Azure の無料アカウントを作成します（本人確認でクレジットカードの入力を求められますが、F0 を選べば課金されません）。
2. <https://portal.azure.com> で上の検索欄に「**Speech services**」（音声サービス）と入力して開き、**作成** を押します。
   - リソースグループ：新規作成（名前は何でも可）
   - リージョン：近い場所（例 **Australia East**、**Japan East**）
   - 価格レベル：**Free F0**
3. 作成が終わったら、リソースを開いて左メニューの「**キーとエンドポイント**」で **キー1** と **場所/リージョン**（例 `australiaeast`）を確認します。
4. このフォルダの `.env.example` をコピーして名前を **`.env`** に変え、メモ帳で開いてキーとリージョンを書き換えて保存します。

```
AZURE_SPEECH_KEY=（キー1）
AZURE_SPEECH_REGION=australiaeast
```

> キーはパスワードと同じです。人に送ったり、スクリーンショットに写したり、GitHub に上げたりしないでください（`.env` は `.gitignore` で除外しています）。

## 2. 起動

| ファイル | 使い方 |
|---|---|
| `start.bat` / `start_all.bat` | `decks` フォルダの中のプレゼンと原稿をすべて読み込みます。画面上のメニューで切り替えます |
| `start_any.bat` | 練習したい .pptx や .txt をこのファイルにドラッグ＆ドロップします |

ブラウザで <http://localhost:8765> が開きます（Chrome か Edge 推奨）。初回はマイクの使用許可を求められるので「許可」を選んでください。終了するときは、黒いウィンドウを閉じます。

`decks\sample.txt` は動作確認用の例です。自分のプレゼンを `decks` に入れて使います（`decks` の中身は Git に入りません）。
テキストの原稿は `# 見出し` の行で区切ると、見出しごとにまとまります。

## 3. 使い方

1. 左の一覧から文を選びます（太字は赤で表示されるので、そこを強く読みます）。
2. **▶ お手本** で聞きます。最初は「お手本の速さ：ゆっくり」がおすすめです。
3. **● 録音**（または **Space** キー）を押して読み、もう一度押すと停止して採点されます。
4. 赤や黄色の単語をクリックして、どの音がずれているかとコツを確認します。単語ごとのお手本も聞けます。
5. **▶ 自分の声** で録音を聞き直し、お手本と比べます。
6. **←/→** キーで前後の文に移動できます。

**アクセント**は en-US / en-AU / en-GB から選べます。ただし「抑揚・リズム」の評価は en-US でしか出ません。

## 採点画面だけ試す（Azure なし）

<http://localhost:8765/?demo=1> を開くと、ダミーの採点結果で画面の動きを確認できます（点数は本物ではありません）。

## プライバシー

録音した音声は採点のために Microsoft Azure に送られます。それ以外の記録（ベストスコア、苦手な音の集計、練習ログ）は、このパソコンの中だけに保存されます。
Azure のキーはこのパソコンのサーバーだけが持ち、ブラウザには10分で切れる一時トークンだけを渡します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `server.py` | ローカルサーバー（プレゼンや原稿から練習文を読み込み、Azure の一時トークンを発行。Python の標準ライブラリだけで動きます） |
| `static/app.js` | 録音・採点・表示 |
| `static/tips.js` | 音ごとの日本語のコツ |
| `.env` | Azure のキー（自分で作成） |
